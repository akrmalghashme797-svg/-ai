# طوفان تواصل - Al-Tofan Chat 🇵🇸
تطبيق مراسلة أندرويد نيتف كامل 100% مبني بأحدث تقنيات **Kotlin** و **Jetpack Compose** بمواصفات أمنية وتكتيكية لثبات وصمود الأبطال.

---

## 🎨 الهوية البصرية والسمات (Visual Branding)
*   **خلفية الشاشة:** أسود عميق (`#0A0A0A`).
*   **رأس الرسالة (المرسل):** أخضر زيتوني داكن (`#1A3A2A`) كرميـز لشجر الزيتون المبارك والعزة.
*   **رأس الرسالة (المستقبل):** رمادي غامق فحمـي (`#1E1E1E`).
*   **شعار التطبيق الرئيسي:** شعار "T" متموج على شكل موجات بحر خضراء تكتيكية يلوذ بها مثلث المقاومة الأحمر الموجه للأعلى 🔺.
*   **الخطوط المعتمدة:** خطوط عريضة مريحة للعين ومتوافقة بالكامل مع نمط وجاذبية خط Cairo في الكتابة العربية والانجليزية.

## 📱 الشاشات والمميزات المضمنة (Screens & Features)

1.  **الصفحة الترحيبية (SplashScreen):**
    *   تعرض "بسم الله الرحمن الرحيم" بشعار الطوفان الرقراق بدقة لمدة 3 ثوانٍ.
    *   تعرض **سورة الفاتحة كاملة** (الآيات 1-7) مرتبة داخل بطاقات عالية التباين، متبوعة بزر "ادخل آمنًا وتواصل 🔓".

2.  **صفحة تسجيل الدخول والتحقق الآمن (Login Screen):**
    *   حقول تعبئة الاسم الحركي والرمز ورقم الموبايل.
    *   محاكاة اتصال لاسلكي مشفر بقمر الاتصالات العسكري لإرسال كود الـ **OTP** وتحقيق هوية المستخدم آمنًا.

3.  **قائمة المحادثات (ChatList Screen - الصفحة الرئيسية):**
    *   أشرطة فلترة وتقسيم ذكي: الكل، القنوات الرسمية، المجموعات، الأرشيف العسكري 📁.
    *   البحث اللحظي السريع وتثبيت المحادثات بالأعلى مع إشعارات الرسائل غير المقروءة.
    *   مؤشر شبكة مرن للغاية:
        *   **متصل آمن:** نظام الند للند مشفر.
        *   **2G وضع الطوارئ:** للشبكات الضعيفة جداً وتوفير استهلاك البيانات.
        *   **أوفلاين:** تظهر فوراً الأيقونة الذهبية العائمة للاعب 🎮 لبدء لعبة صامد 2D!

4.  **غرفة الدردشة الفردية والعامة (Chat Screen):**
    *   فقاعات مراسلة متجاوبة مع قراءة حالة صحين متطورة ومطابقة (✓✓).
    *   **اتصال صوتي Agora VoIP:** محاكاة مكالمات صوت عسكرية ذكية وواضحة جداً مع لوحة أمواج صوتية رنانة تتحرك حركياً.
    *   **وضع الطوارئ (2G Mode):** تقليص حجم الحروف والكلمات وضغط الكلمات العربية المعتادة لضمان وصولها بنجاح بأقل سعة إنترنت، مع إمكانية فك الضغط التلقائي بضغطة زر مفردة داخل الشات!
    *   **تسجيل المايك الصوتي:** تسجيل فلاتر صوتية بموجة حمراء متحركة بديناميكية تامة بمجرد الإبقاء على ضغط زر المايكروفون.
    *   **متجر الاستكرات التكتيكية:** استكرات وصور غزة العزة، قبة الصخرة، حنظلة ومفتاح العودة.

5.  **لعبة صامد الأوفلاين 2D (Samed Game):**
    *   لعبة حركة ثنائية الأبعاد تعمل بالكامل داخل محرك Jetpack Compose Canvas الخفيف بـ (60 إطار بالثانية).
    *   التحكم في سحب وتحريك البطل (المجاهد) يميناً ويساراً لجمع الرموز (العملات 🪙، غصن الزيتون 🌿، مفتاح العودة 🔑) وتفادي الصواريخ والقنابل المتساقطة 💥.
    *   حفظ أوتوماتيكي لأعلى مجموع نقاط المحارب مباشرة في قاعدة بيانات **Room Database** المحلية وتحويلها تلقائياً إلى معايير أوسمة شجاعة (برونزي، فضي، ذهبي 🎖️) تظهر في قائمة شرف الصامدين الأسبوعية!

6.  **لوحة الإعدادات العسكرية (Settings Screen):**
    *   **هوية الطوفان:** تفعيل بروتوكولات الند للند وتوليد مفاتيح تشفير الاستعادة والمزامنة.
    *   **متجر الصمود:** استبدال الأقراص والنقاط التي تجمعها في اللعبة بملصقات فلسطينية فريدة لفتحها بداخل الشات!
    *   **مكتبة الصمود:** مستندات وكتب تاريخية وتكتيكية لتعزيز الوعي في أوقات الحصار (مثل دليل الصمود الطبي والتقني وتاريخ القضية).

## 🛠️ الهندسة ومكونات المشروع (Architecture & Tech Stack)
*   **لغة العمل:** Kotlin 100%.
*   **واجهة المستخدم:** Jetpack Compose + Material Design 3.
*   **حفظ البيانات محلياً:** Room Persistent Database (التي تعوض Hive في أندرويد نيتف) لسرعة الوصول وأدائها المتين وخلوها من التعارضات.
*   **التشغيل وتوافق جافا:** Java 17 كهدف تجميعي أساسي.

## 🚀 كيفية تشغيل وتوصيل منصة Firebase و Agora

لتوصيل مشروع ببيئات العمل الحية والإنتاجية بدقة، اتبع الخطوات التالية:

### أولاً: توصيل Firebase SDK
1. أنشئ حساباً على منصة [Firebase Console](https://console.firebase.google.com/).
2. أنشئ مشروعاً جديداً وضع اسم حزمة التطبيق (Package Name): `com.akrmalghashme797.svg`.
3. حمل ملف `google-services.json` من الإعدادات وقم بنسخه ولصقه بمحاذاة مجلد التطبيق في المسار التالي:
   ```text
   /app/google-services.json
   ```
4. لتشغيل الإرسال الفعلي لرسائل الـ SMS، تذكر تفعيل **Phone Authentication** في إعدادات Firebase Auth.

### ثانياً: تفعيل مكتبات Firebase الحية بملف Gradle
لربط خدمات جوجل الحية والمصادقة التلقائية، قم بإلغاء تعليق وتضمين إضافات الـ Firebase في dependencies بملف `app/build.gradle.kts`:
```kotlin
// dependencies {
implementation("com.google.firebase:firebase-auth-ktx")
implementation("com.google.firebase:firebase-firestore-ktx")
implementation("com.google.firebase:firebase-storage-ktx")
// }
```

### ثالثاً: دمج Agora Voice RTC للمكالمات الحية
للارتقاء بالمحاكاة إلى تواصل حقيقي بالصوت عبر الإنترنت باستخدام منصة **Agora**، أضف السطر التالي بقائمة الاعتمادات:
```kotlin
implementation("io.agora.rtc:full-sdk:4.2.6")
```
ثم قم بوضع الـ AppId الخاص بحسابك بـ Agora بداخل كود `ChatScreens.kt` لتنشيط غرف الـ RTC فوراً.

### رابعاً: تشغيل وبناء التطبيق
*   افتح المشروع داخل بيئة **Android Studio**.
*   اضغط على **Sync Project with Gradle Files**.
*   اضغط على **Run** لتشغيل التطبيق المترجم مباشرة في الجهاز أو محاكي البث المباشر.
